# TypeScript Assignment

## Overview

This assignment practices core TypeScript features through a set of small functions and classes, plus two short blog posts explaining related concepts.

### Solution (`solutions.ts`)

| Item | What it demonstrates |
| --- | --- |
| `multiplyValue` | Default parameter values |
| `processInput` | Union types and type narrowing with `typeof` |
| `formatCoordinate` | Readonly tuples |
| `concatenateArrays` | Generics with rest parameters |
| `getPopularCourses` | Interfaces and filtering arrays of objects |
| `pluckValues` | Generic constraints with `keyof` |
| `Employee` / `Manager` | Classes, inheritance, `protected` and `private` members |
| `validateAgeAsync` | `async`/`await`, Promises and error handling |

## Blog Posts

1. [Access Modifiers in TypeScript](./access-modifiers.md): explains `public`, `private`, `protected` and `readonly` with an `Account` example.
2. [Combining Union and Intersection Types in TypeScript](./union-and-intersection-types.md): shows how `|` and `&` work together using a student record example.
